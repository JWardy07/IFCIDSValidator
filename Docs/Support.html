Privacy Policy - IFC IDS Validator

This policy explains how IFC IDS Validator handles data.

Effective date: 27 March 2026

1. Data We Process

IFC IDS Validator lets you import IFC and IDS files for on-device validation and reporting.

  • We process files you choose from your device via Apple file pickers.
  • File access is limited using user-selected permissions (security-scoped access on Apple platforms).

2. Data Collection and Tracking

In the current build, IFC IDS Validator is designed to run locally and does not require account sign-in.

  • No account creation is required.
  • No in-app social profile or identity features are provided.
  • No cloud upload is required for core validation workflows.

If this changes in a future version, this policy will be updated before release.

3. How Files Are Used

  • Imported IFC/IDS files are used to read metadata and run local validation checks.
  • Generated reports are exported only when you explicitly choose to export them.
  • You control where exported reports are saved.

4. Data Retention

  • Imported file selections are session-oriented in the app workflow.
  • You can clear imported content at any time using in-app clear actions.
  • Files remain on your device unless you explicitly export/share them.

5. Third-Party Services

The app may rely on standard Apple platform services required for app distribution and operation (for example, App Store delivery and OS-level file selection). No additional third-party data broker integration is intended in the current build.

6. Children’s Privacy

This app is a professional BIM utility and is not directed to children under 13.

7. Your Controls

  • Choose which files to import.
  • Clear imported IFC/IDS data from the app session.
  • Choose whether to export reports and where to save them.
