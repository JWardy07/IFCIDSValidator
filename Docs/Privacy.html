IFC IDS Validator Support

Help for iPhone, iPad, and Mac Catalyst users.

Last updated: 27 March 2026

Contact

For support requests, bug reports, or feature requests, email: jamiepward@googlemail.com

When reporting an issue, include:

  • Device type and OS version
  • App version/build
  • A short description of the expected result and what happened
  • If possible, the IFC and IDS sample that reproduces the issue

Quick Troubleshooting

  • Import fails: Re-open the file and make sure it has a supported extension (.ifc, .ifczip, .ids, .xml).
  • Validation appears slow: Large MEP models can take longer. Keep the app open and check the progress indicator.
  • No export output: Run validation first, then export report in TXT/JSON/CSV.
  • Mac file access issues: Re-import the file to refresh security-scoped access permissions.

Supported Formats

  • IFC model input: .ifc, .ifczip
  • IDS input: .ids, .xml (IDS-compatible XML)
  • Report export: .txt, .json, .csv
